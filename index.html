AgroVista

Consulta datos climáticos reales de la API pública de NASA POWER para una parcela y compara la última semana contra el promedio histórico del mismo período.

01 — Ubicación de la parcela
Seleccioná un punto en el mapa
Fuente: OpenStreetMap Nominatim (geocoding), NASA GIBS (imaginería satelital)
02 — Cultivo
Fuente: FAO Crop Calendar + base de datos agronómica de referencia
03 — Estado hídrico general
--
Fuente: NASA POWER (precipitación, temperatura, humedad)
04 — Últimos 14 días vs. mismo período, año anterior
Fuente: NASA POWER API (datos diarios point)
05 — Recomendación para tu cultivo
--
Fuente: FAO + rangos agronómicos de referencia (no reemplaza asesoramiento profesional)
06 — Precipitación diaria (mm) — últimos 14 días
Fuente: NASA POWER API (PRECTOTCORR)

Fuente de datos principal: power.larc.nasa.gov/api (NASA POWER, acceso público, sin API key). Se piden precipitación (PRECTOTCORR), temperatura a 2m (T2M), humedad relativa (RH2M) y humedad de suelo modelada (GWETROOT, GWETTOP) diarias. Para humedad de suelo satelital de mayor precisión (SMAP), la vía de producción es AppEEARS con cuenta de NASA Earthdata Login — requiere backend por su flujo asincrónico. La recomendación de cultivo es un motor de reglas simplificado con rangos agronómicos aproximados: no reemplaza el consejo de un ingeniero agrónomo local.
